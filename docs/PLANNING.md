# Draftlog 기획

## 한 줄 소개

ChatGPT·Claude 웹에서 대화하며 고쳐 쓴 자소서 답변을 **문항별 버전**으로 남기고, 무엇이 바뀌었는지 비교하는 브라우저 확장 프로그램.

## 문제

취업 준비생 대부분은 자소서를 ChatGPT나 Claude **웹 채팅**으로 고친다. 이 과정에서 반복적으로 생기는 불편:

| 불편 | 지금 하는 방법 | 결과 |
| --- | --- | --- |
| 여러 번 고친 답변 중 어떤 게 나았는지 모름 | 대화창을 위로 스크롤, 메모장에 복붙 | 좋은 버전을 잃어버림 |
| 무엇이 바뀌었는지 안 보임 | 두 창을 띄워 눈으로 비교 | 사실관계가 몰래 바뀐 걸 놓침 |
| 글자수 제한 확인 | 글자수 세기 사이트에 매번 붙여넣기 | 공백 포함/제외/바이트 기준이 회사마다 달라 실수 |
| 같은 경험을 여러 회사에 재사용 | 예전 대화를 뒤짐 | 어느 회사에 어떤 문장을 썼는지 모름 |
| 요청할 때마다 문항·제한·공고를 다시 입력 | 매번 타이핑 | 요청 품질이 들쭉날쭉 |

## 대상 사용자

- 무료 요금제로 ChatGPT·Claude 웹을 쓰는 취업 준비생 (API 키 없음)
- 동시에 5~20개 회사에 지원하며 회사당 문항 2~5개를 관리하는 사람

## 핵심 원칙

1. **쓰던 곳에서 그대로.** 새 채팅 서비스를 만들지 않는다. 사용자가 이미 쓰는 chatgpt.com, claude.ai 옆에 붙는다.
2. **API 키·서버 없이.** 무료 사용자도 바로 쓸 수 있어야 한다. 데이터는 사용자 브라우저에만 저장한다.
3. **git처럼, 하지만 git 용어 없이.** 버전·비교·최종본 정도만 노출한다.

## 기능 범위

### MVP (v0.1)

- 지원서(회사·직무·마감일) → 문항(글자수 제한·세는 기준) → 버전 구조
- 글자수: 공백 포함 / 공백 제외 / 바이트(한글 2, 영문 1, 줄바꿈 2)
- 직접 쓴 초안 자동 저장 + 버전 저장(메모 포함)
- 채팅 답변 저장: 답변 위 버튼, 드래그 선택 저장, 우클릭 메뉴
  - 저장 전 내용 수정, 저장할 문항 선택
  - 출처(ChatGPT/Claude)와 대화 링크 기록
- 요청문 보내기: 첨삭 / 글자수 맞추기 / 다듬기 / 직접 요청 → 채팅 입력창에 삽입
- 버전 비교(어절 단위 diff), 최종본 표시, 초안으로 불러오기
- 전체 검색, JSON 백업·복원

### 이후 후보

- 문항 템플릿(자주 나오는 문항 유형별 요청문)
- 여러 기기 동기화(선택적 계정 연동)
- 스터디원과 버전 공유·코멘트
- 마감 임박 알림

## 성공 기준

- 설치 후 5분 안에 첫 지원서·문항을 만들고 채팅 답변 1개를 버전으로 저장
- 문항당 평균 3개 이상 버전이 쌓임 (= 비교 기능을 실제로 쓰는 상태)
