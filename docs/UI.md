## 채팅 페이지 (shadow DOM)

- **답변 저장 버튼**: 답변에 마우스를 올리면 답변 오른쪽 위에 `자소서에 저장` 알약 버튼. 스크롤 시 따라다니고, 벗어나면 0.5초 뒤 사라짐.
- **선택 영역 저장 버튼**: 5글자 이상 드래그하면 선택 끝에 `선택 영역 저장`. 입력창 안 선택에는 뜨지 않음.
- **저장 카드**: 화면 오른쪽 위 고정 카드.
  - 저장할 문항 선택(회사별 그룹, 패널에서 보던 문항이 기본값)
  - 내용 편집 textarea + 글자수(문항 기준)
  - 메모(기본값 `ChatGPT 답변`), `패널의 초안도 이 내용으로 바꾸기` 체크
  - `v4로 저장` — 다음 버전 번호를 버튼에 보여줌
  - Esc 닫기, Ctrl/⌘+Enter 저장, 카드 안 키 입력은 페이지로 전달하지 않음

## 시각 요소

| 토큰 | 라이트 | 다크 | 용도 |
| --- | --- | --- | --- |
| `--accent` | `#1D6A4E` | `#5DC39A` | 주요 버튼, 선택 상태, 최종본 |
| `--add-*` | `#D4EFDF / #11573A` | `#15382A / #8FE0B6` | 비교: 추가 |
| `--del-*` | `#F6DADA / #962C2C` | `#3E1D1D / #F2A5A5` | 비교: 삭제, 마감 임박 |
| `--gp-*` | `#DBEBF3 / #1F6588` | `#16303D / #86C3E3` | ChatGPT 출처 |
| `--cl-*` | `#F6E3D8 / #A94F25` | `#3A2419 / #F0A47F` | Claude 출처 |

- 답변 본문(초안, 버전, 비교)은 명조 계열(`Gowun Batang` → 시스템 명조)로 "원고"처럼 보이게 하고, UI는 고딕.
- 숫자(글자수, 날짜)는 고정폭.
- 삭제는 누르면 버튼이 `한 번 더 누르면 삭제`로 바뀌고 3초 뒤 원래대로 (확인 대화상자 없음).

## 문구 원칙

- 사용자가 아는 말로: 커밋 → **버전 저장**, diff → **비교**, HEAD → **초안**
- 오류는 무엇이 안 됐고 어떻게 하면 되는지: "입력창을 찾지 못해 복사했어요. 붙여넣어 주세요."
